2. HTML পেস্ট করুন অথবা ফাইল দিন

HTML ফাইল দিলে বর্তমান title এখানে দেখা যাবে।

ডিফল্ট NO থাকবে—তখন কোনো তারিখ বদলাবে না। YES করলে ক্যালেন্ডার থেকে বেছে নেওয়া তারিখ HTML-এর ভেতরের পরিচিত তারিখে বসবে। HTML-এর Title অপরিবর্তিত থাকবে।

এখানে HTML দিলে শুধু <title> ট্যাগের টাইটেল সংগ্রহ করা হবে।

3. HTML ফাইলের JS Link পরিবর্তন করুন

HTML ফাইল নির্বাচন করুন অথবা উপরের HTML source বক্সে কোড দিন। আগে পরিচিত JS লিংক বদলাবে; না পেলে শেষ external script link বদলাবে। কোনো external script না থাকলে নতুন script যোগ হবে।

HTML ফাইল নির্বাচন করলে সেটি স্বয়ংক্রিয়ভাবে HTML source বক্সে লোড হবে। আপলোড করলে বর্তমান <title> এই বক্সে দেখা যাবে। নতুন title লিখে “Title আপডেট করুন” চাপলে HTML-এর <title> ট্যাগ এবং পুরোনো title-এর একই লেখা যেখানে আছে সেখানেও আপডেট হবে। এই বাটন না চাপলে আগের title-ই থাকবে—শুধু বক্সে লিখে রাখলে পরিবর্তন হবে না। তারপর “লিংক আপডেট করুন” চাপুন। JS URL ফাঁকা রাখলে ডিফল্ট লিংক ব্যবহার হবে।

HTML ফাইল নির্বাচন — Unlimited Titles

যতগুলো HTML ফাইল চান নির্বাচন করুন, তারপর “সব ফাইল থেকে Title বের করুন” চাপুন। একাধিক ব্যাচ থেকেও টাইটেল যোগ করতে পারবেন।

প্রতিটি HTML ফাইলের <title> ট্যাগ থেকে টাইটেল সংগ্রহ হবে। একই টাইটেল একবারই দেখানো হবে।
